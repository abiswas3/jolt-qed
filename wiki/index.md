# Jolt QED Project Wiki

This project is an attempt to formalise the [Jolt zkVM](https://github.com/a16z/jolt) in Lean 4.

> [!IMPORTANT]
> This project is currently under active development. We will aim to keep the wiki up to date, but the code and roadmap are subject to change.

## Active Projects

1. [Bytecode Expansion](projects/bytecode-expansion/README.md) — proving that each Jolt expansion of a RISC-V instruction agrees with the trusted Sail semantics.
2. [Lookup Table Verification](projects/lookup-table-verification/README.md) — proving that Jolt's MLE evaluators really do compute the multilinear extension of each instruction's lookup table.
