# Contributing to Jolt-Qed

We welcome contributions from anyone willing to work in good faith with other contributors and the community.

## Code Of Conduct

This project follows the
[Contributor Covenant Code of Conduct, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Issues

All code likely contains bugs. 
Even code that claims to formally verify that aren't any.
If you find a problem write to us.
For bug reports, and feature requests, please open an issue
in this repository.

For general questions, you are welcome to email us at [jolt.qed@randomwalks.xyz](mailto:jolt.qed@randomwalks.xyz).
Before preparing your correspondence, please read the code of conduct above, and also make sure to follow the rules outlines [here](http://www.catb.org/esr/faqs/smart-questions.html).
Beyond that, there are no set rules. 
Use common sense.

## Pull Requests

Firstly, we expect AI agents as part of developer workflows.
So it is perfectly reasonable to send us code written by an AI agent, as long as you have read and understood what your agent wrote, and can have a meaningful discussion about it.
All documentation and correspondence, however, must be human written, or at least human reviewed.
Put simply, [it is rude to show AI output to people](https://distantprovince.by/posts/its-rude-to-show-ai-output-to-people/?utm_source=chatgpt.com).

Please ensure that pull requests:

- Explain what changed and why.

- If it's a major contribution to the design of the project, we expect some sort of a write up explaining your thought process. There is no strict format, blogs, PR comments, or anything that gets the job done is fine.
